## 🛠️ Funciones de Utilidad

### useScryvedTranslations()
Hook personalizado para acceder a todas las traducciones de forma estructurada.

```tsx
const { hero, services, security, contact } = useScryvedTranslations();
```

### generateScryvedMetadata()
Genera metadata optimizada para Next.js App Router.

```tsx
export const metadata = generateScryvedMetadata({
  title: '...',
  description: '...',
  keywords: [...],
  locale: 'es'
});
```

### SchemaMarkup
Componente para inyectar JSON-LD en el DOM.

```tsx
<SchemaMarkup schema={organizationSchema} />
```
